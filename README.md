# RoleWorld Engine

**RoleWorld Engine** is a handcrafted 2D engine written in C# (.NET 8+) using Silk.NET.
Its purpose: generate procedural worlds (maps, biomes, terrain) from a seed, with a minimalist 2D pixel-art rendering.

---

## Current Features

- Procedural strategic map generation (islands, biomes, terrain) from a seed
- Immediate-mode 2D rendering via Silk.NET (OpenGL, GLFW)
- Handcrafted architecture, no third-party engine layer
- Basic entity system foundation (work in progress)

---

## Technologies

- **Language:** C# on .NET 8+
- **Low-level API:** Silk.NET (OpenGL, GLFW, Input)
- **Architecture:** fully handcrafted, no external engine dependency
- **Rendering:** immediate-mode 2D, minimalist pixel-art style
